# My Python Journey 🐍

My personal journey learning Python from the basics. This repository collects
the exercises I build as I progress, organized by topic so each folder maps to
a section of what I'm learning.

## 📚 Sections

| Folder | What it covers |
|--------|----------------|
| [`01-basics/`](01-basics/) | Printing, variables, user input, data types, casting, basic operations and string formatting |
| [`02-operators/`](02-operators/) | Comparison operators, logical operators (`and`/`or`/`not`) and booleans |
| [`03-conditionals/`](03-conditionals/) | `if` / `elif` / `else`, nested and complex conditionals, ternary operator and `match/case` |
| [`04-strings/`](04-strings/) | Indexing, slicing, and string methods (`len`, `upper`, `lower`, `strip`, `replace`, `split`, `join`) |
| [`05-loops/`](05-loops/) | `for` and `while` loops: counters, accumulators, `break`/`continue`/`else`, input validation and sentinels |
| [`06-matrices/`](06-matrices/) | Nested loops and matrices: grids, patterns, traversal, transpose and search |
| [`07-iteration-tools/`](07-iteration-tools/) | `enumerate`, `zip`, `reversed`, and `sorted` with `key` / `lambda` |

## ▶️ How to run an exercise

Each file is a standalone script. Run any of them with:

```bash
python3 05-loops/guess_number.py
```

## 🎯 About this repo

These exercises are part of my learning process, so they focus on clarity and
on practicing one concept at a time. Comments explain the reasoning behind each
solution.
